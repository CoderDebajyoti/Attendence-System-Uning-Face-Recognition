# Attendance Registry History & Filters

This document describes options for filtering, searching, and viewing historical student check-in records.

## Data Views
1. **Attendance Registry Table**: The master record table displays:
   `Attendance ID | Student ID | Student Name | Time | Status | Match Score | Source`
2. **Student Details History Panel**: Accessible under the Student Profile screen, this panel aggregates personal attendance rates and lists the 5 most recent records.

## Query Parameters
Administrators can refine historical lists using the top filter card:
- **Search Bar**: Queries matching student codes, first/last names, or roll numbers.
- **Date Selector**: Filters records on a specific day (`YYYY-MM-DD`).
- **Dropdown Filters**:
  - **Status**: PRESENT, LATE, ABSENT, EXCUSED.
  - **Source**: FACE_RECOGNITION, MANUAL.
  - **Academic Structure**: Filter by Department or Course.
